# CodeAlpha_IrisFlowerClassification
CodeAlpha Data Science Internship, Task 1.  Classifies Iris flowers into setosa, versicolor, or virginica using sepal and petal measurements. Compares five classifiers (Logistic Regression, KNN, Decision Tree, Random Forest, SVM) and evaluates with accuracy and a confusion matrix.  Python, Pandas, Scikit-learn, Matplotlib, Seaborn.
